# Research report interface

A small standalone browser example created for this showcase. It is an interface study, not an export of the private application.

Open `index.html` in a browser or serve this folder with `python -m http.server 8000`. There are no dependencies, accounts, network calls, or production data.

The report study switches between three invented indexed-value paths. It contains no strategy rules or actual investment performance.

The styling and JavaScript are shared between the two examples so each folder remains self-contained.
