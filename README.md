# Varun Coding Showcase

Examples of hobby code I've developed for personal projects. Majority of codebase is held private to keep proprietary.

## Explore

| Example | What to inspect |
| --- | --- |
| [SheetFreak](sheetfreak/) | VBA source, conservative number-format parsing, exact formula copying, dependency-aware fill/calculate/freeze, Office ribbon integration, and native test modules. |
| [Workout interface](examples/workout-interface/) | A standalone mobile-friendly UI study with synthetic sets, volume calculations, row editing, and browser-local recovery. |
| [Research report interface](examples/research-report/) | A standalone report-layout study with selectable synthetic series and accessible SVG rendering. |

## Run the interface examples

Open either example’s `index.html` in a browser, or serve its folder using `python -m http.server 8000`. No package installation or API keys are required.

## Scope

This is a deliberately limited showcase and includes projects that are work-in-progress. All displayed datasets are synthetic. It contains no investment strategy, market dataset, personal workout history, production configuration, or unpublished research.

SheetFreak is distributed as source, ribbon XML, test modules, and build instructions. Its original compiled add-in is excluded. Recorded native test results are historical project evidence; they were not independently rerun while preparing this showcase.
